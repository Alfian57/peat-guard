# Hero video

The landing page uses `peatland-hero.mp4` as its muted, looping hero background.
The MP4 is stored locally so the page does not depend on a third-party player.

## Current clip

- Source: [A tranquil aerial view of a swamp surrounded by lush trees](https://www.pexels.com/video/aerial-shot-of-a-swamp-8744855/)
- Creator: Roman Odintsov
- Source format: 4K MP4, 16 seconds
- Local format: H.264 MP4, 1920 × 1012, no audio
- License: [Pexels License](https://www.pexels.com/license/)

This is generic swamp footage, not a verified peatland or an Indonesian
monitoring site. The hero labels it as illustrative. Replace it with approved
peatland footage if the project needs location-specific imagery; keep the
`peatland-hero.mp4` filename so no code change is needed.
